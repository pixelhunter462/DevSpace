# DevSpace — Developer Toolkit

DevSpace is a free, responsive, browser-based toolkit for developers. It is built with vanilla HTML, CSS and JavaScript, with no build tools or dependencies required.

## Features

- **Code editor:** write HTML, CSS and JavaScript and preview the result in a sandboxed iframe.
- **Color picker:** choose colors and copy HEX/RGB values.
- **JSON formatter:** validate, pretty-print and minify JSON.
- **URL encoder:** encode and decode URL components.
- **Quick notes:** save and delete notes using browser local storage.
- **Pomodoro timer:** focus, short-break and long-break modes.
- **Dark/light theme:** remembers the selected theme in this browser.
- **Responsive layout:** works on desktop and mobile screens.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No installation is needed.

## Publish with GitHub Pages

1. Create a new GitHub repository named `devspace`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Privacy

Notes and theme preference are stored in the browser's local storage. They are not uploaded to a server. Clearing browser data may remove them.
